# myfleet.gg

Public issue tracker for **[myfleet.gg](https://myfleet.gg)** — an interactive 3D Star Citizen fleet viewer.

This repository does **not** contain the platform's source code. It exists so users can report bugs and request features in one place.

## Report a bug or request a feature

Open an issue: **https://github.com/Lesani/myfleet.gg/issues/new**

Before filing, a few things that help a lot:

- **What you did** — the steps that led to the problem.
- **What you expected** vs. **what happened**.
- **Browser & device** — e.g. Chrome 142 on Windows 11, Safari on iPhone 15, etc.
- **Screenshot or screen recording** if the bug is visual.
- **Console errors** if you know how to grab them (F12 → Console).

For feature requests, describe the use case ("I want to do X so that Y") rather than a specific implementation — it gives more room to find a good solution.
